# Contributing

This is a small demo repository for a talk and blog series.

Contributions are welcome if they improve:

- clarity of the architecture
- safer guardrail examples
- read-only Kubernetes triage workflows
- MCP or Agentgateway verification steps
- public-safe sample manifests

Please do not add real organization names, internal hostnames, credentials, tokens, account IDs, Slack workspace IDs, Teams tenant IDs, or production cluster details.
